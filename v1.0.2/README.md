# 音匣 SoundVault v1.0.2

> 本地音效库管理器。Windows 10 / 11 · WPF (.NET 10) · 单文件 exe · 不联网、不改你的文件。
>
> 这一版的重点是**快**：大库导入秒级可用，搜索和滚动不再一顿一顿；安装与设置也重做了一遍。
> 详细改动见 [`修改意见.md`](修改意见.md)，用户手册见 [`使用说明书.md`](使用说明书.md)。

## 这一版做了什么

| 项 | 结果 |
|---|---|
| 两阶段索引 | 扫描只读文件头，波形后台补。1.48 GB / 60 文件 **1709 ms → 20 ms**；10 万文件 10.1 秒 |
| 秒搜 | 整库缓存 + 拼音预热 + 增量过滤 + 防抖。拼音首查 **49 ms → 1 ms** |
| 文件夹与音效同屏 | 库根同时显示子文件夹和根目录音频 |
| 快捷入口跨库 | 全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 都是全库；库与文件夹仍只看本库 |
| 平滑滚动 | 左右两栏逐帧缓动，可关、三档速度，跟随系统动画设置 |
| 进度条 | 两行：说明 + 数字/百分比/剩余/文件名 + 取消 |
| 安装器 / 设置面板 | 向导式安装（不再弹系统对话框）、设置五页、外观内嵌 |
| 移除 | 「已用」角标、省电模式、AI 自动打标签（准确率不足） |

## 构建

```powershell
.\build.ps1 -Version 1.0.2
# 产物：_local\dist\  →  音匣.exe + SoundVault-1.0.2-Setup.exe

# 只出应用、不出安装包
.\build.ps1 -Version 1.0.2 -SkipInstaller

# 全量验收（31 项）
.\tools\verify-all.ps1
```

## 已知限制

- 只有 Windows（WPF），没有跨平台计划
- 网络盘 / 移动硬盘扫描会慢一些
- 拖拽到某些宿主不生效时，用 `Ctrl+C` 复制文件再粘贴
- 单文件未签名，SmartScreen 可能提示"未知发布者"
