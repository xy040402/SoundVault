# 音匣 v1.0.2 · 修改意见与实现说明
> 这一版的主要改动：安装与设置重做、导入与搜索提速、界面细节修正。下面按"问题 → 根因 → 做法 → 实测"逐条写。

---

## 一、核心问题一览

| # | 问题（用户能感觉到的） | 根因 | 结果 |
|---|---|---|---|
| 1 | 大库导入要等很久 | 扫描时为了画波形，把每个文件从头读到尾 | 1.48 GB / 60 文件 **1709 ms → 20 ms**；10 万文件 10.1 秒 |
| 2 | 搜索时一个字一个字地卡 | 每次按键都重读全库 + 全量过滤排序 | 拼音首查 **49 ms → 1 ms** |
| 3 | 补波形结束会卡一下 | 补完把整库卡片重建 | 只贴回可见卡片（5 千库 **28 ms**） |
| 4 | 导入进度条"看着不动" | 进度条填充元素没写宽度，缩放倍率乘在 0 上 | 改成两行进度条 + 可取消 |
| 5 | 滚轮滚起来是"闪现" | 滚动偏移一步到位，没有动画 | 左右两栏逐帧缓动，可关可调 |
| 6 | 有子文件夹时，根目录音频不见了 | 视图在"只画文件夹"和"只画音频"之间二选一 | 两段同时显示 |
| 7 | 快捷入口只看当前库 | 数据源写成了 `FilesUnder(当前库)` | 全部音效/收藏/最近导入/最近播放/标签/重复检查/搜索 全部跨库 |
| 8 | 删库后重新导入，旧状态还在 | 删库没清评分、收藏、播放记录、集合引用、标签关联 | 删库时一并清理 |
| 9 | 安装失败的提示看不懂 | 失败原因被吞，只弹系统错误 | 失败页给原因 + 一键复制诊断信息 |
| 10 | 勾了"创建开始菜单快捷方式"却没出现 | 快捷方式建在嵌套目录里，且没校验 | 直接放 Programs 根，装完当场校验 |
| 11 | 96k 音频放不出来 | 容器嗅探 + 解码两处都没覆盖 | 已修，实测可播 |
| 12 | 智能文件夹右键删不掉 | 右键事件被列表控件吃掉 | 用 Preview 事件 + 命中行选中 |
| 13 | 库根直接放音频时视图空白 | 有子文件夹就只走文件夹分支 | 与 6 一起修 |

## 二、逐项说明

### 1. 两阶段索引：扫描只读文件头

**现象**：拖进一个几百 MB 的音效包，要盯着进度条等很久；库越大越慢，耗时和总字节数成正比。

**根因**：扫描阶段为了拿到波形峰值，`WavReader` 会把整个文件的采样读完再降采样。

**做法**：

| 阶段 | 做什么 | 什么时候 |
|---|---|---|
| ① 快扫 | 只读文件头（采样率/声道/位深/时长），峰值留空 | 导入、启动增量扫描 |
| ② 补波形 | 查 `peaks IS NULL` 的行，每批 200 个解码写回 | 扫描结束后自动在后台跑 |

- 库扫完立刻出现在界面上，波形随后"长"出来
- 补波形可以取消，也可以中途关软件，下次启动继续（实测中断后剩余 26,000 个自动续上）
- 并发 3 线程，不抢播放和滚动

**实测**：

| 指标 | 改动前 | 现在 |
|---|---|---|
| 扫描 60 个文件 / 1.48 GB | 1709 ms | **20 ms** |
| 补波形（后台） | 扫描内完成 | 2512 ms |
| 10 万文件扫描 | — | 10.1 秒（约 0.1 ms/文件） |
| 10 万文件补波形 | — | 18.1 秒（5,500 个/秒） |

### 2. 秒搜

**根因**：每次按键 `ReadAllRows()` 读全库（含峰值 BLOB）→ 建卡片对象 → 全量过滤 + 排序。

**做法**：

| 项 | 说明 |
|---|---|
| 整库缓存 | 按「库 + 数据版本号」缓存卡片；换库、扫描完成、导入、删库时失效 |
| 拼音预热 | 建缓存时并行算好首字母和全拼，避免第一次打拼音卡一下 |
| 增量过滤 | 新关键字是上次的前缀、排序和收藏没变 → 只在上一批结果里再筛 |
| 输入防抖 | 110 ms，连打几个字只算一次 |
| 后台预热 | 启动后就偷偷把缓存建好，用户第一次点搜索不用等 |

**实测**（10 万条）：首次进搜索 53 ms，逐字增量 2 ms，拼音 `bd` 3 ms；拼音首查从 49 ms 降到 1 ms。

### 3. 补波形结束时不再重建整库

**现象**：补波形结束的一瞬间界面卡 1–2 秒（10 万条时最明显）。

**根因**：补完调用 `ReloadCurrentView()`，等于把整库卡片重新造一遍。

**做法**：改成 `RefreshVisiblePeaks()` —— 只查当前视图里峰值还空着的行（分批 800 条），把新峰值贴回卡片。

**实测**：5 千库「补齐完成」到「刷新可见卡片」间隔 **28 ms**。

### 4. 进度条重做

原来的进度条：半透明一条，填充元素没写宽度，`ScaleX` 乘在 0 上，看起来永远不动。

现在两行：

```
正在补齐波形图，您可以继续操作
22 / 40　56%　·　剩余 2 秒　·　AK47_BURST_20.wav  ━━━━━━━━  [取消]
```

- 第一行说"在做什么、能不能继续操作"
- 第二行是数字 / 百分比 / 剩余时间 / 文件名 + 进度条 + 取消
- 各阶段文案分开：枚举 / 比对索引 / 读取音频头 / 写入索引 / 补齐波形

### 5. 滚轮平滑滚动

**做法**：滚轮只改「目标偏移」，每帧用 ease-out 曲线逼近，`CompositionTarget.Rendering` 驱动。

| 项 | 说明 |
|---|---|
| 范围 | 左侧栏 + 右侧网格 |
| 时长 | 快 100 / 标准 140 / 缓 220 ms，设置里可调；可整体关闭 |
| 系统设置 | 跟随 Windows「显示动画」，关掉就退回一步到位 |
| 边界 | 拖滚动条立即跟手；快速连滚累加目标不吞键；内容替换时偏移归零 |

### 6. 文件夹和音效同屏

**根因**：`ShowLibrary` 里是 if/else —— 有子文件夹就只画文件夹，不读根目录音频。

**做法**：两段一起画。文件夹区高度自适应（最多约两行，多了自己滚动），音频区占剩下的空间。

**实测**：库根「3 个文件夹 · 5 个音效（根目录）」，子文件夹「1 个文件夹 · 2 个音效」都显示正常。

### 7. 快捷入口跨库

| 入口 | 范围 |
|---|---|
| 全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 | **全部库** |
| 侧栏的库 / 文件夹 | 只看该库（面包屑上看得出作用域） |

路径里不再出现某个库的名字；一个库都没有时显示空状态而不是报错。

### 8. 安装器与卸载器

- 全程向导式页面，**不再弹 Windows 原生对话框**（关旧版本、卸载旧版本、删除数据确认都在页面内）
- 装到受保护目录会自动提权；装完可直接启动
- **开始菜单快捷方式**：直接放 `Programs\音匣 SoundVault.lnk`，装完用 `File.Exists` 校验，失败退回 WScript 再建一次
- 失败页给：出错步骤、原因、日志末尾、诊断信息一键复制、打开日志目录
- 卸载可选「保留数据」或「彻底删除」，删数据有二次确认

### 9. 设置面板

左导航 + 五页：

| 页面 | 内容 |
|---|---|
| 常规 | 主题（深/浅）、窗口置顶、平滑滚动（开关 + 三档）、重看新手引导 |
| 外观 | 主色（6 预设 + HEX）、最近使用（8 个）、收藏（10 个）、面板强度、圆角、云母 |
| 导出与命名 | 命名模板、文件名清洗规则、文件关联 |
| 数据与日志 | 数据位置、打开数据目录、重建索引、备份数据、便携模式、日志、诊断包 |
| 关于 | 版本、数据目录、反馈入口 |

- 外观不再是独立对话框，改在页面内即时预览，点「取消」全部还原
- 修掉三处遗留：置顶时亮错图标、浅色主题悬停色写死、导航点了不切换

### 10. 日志与诊断包

- `app-*.log` / `setup-*.log`，单文件 5 MB，保留 5 个
- 记录：启动环境、扫描（文件数/耗时/失败文件）、解码失败、播放失败、导入导出、安装步骤、崩溃堆栈
- 不记录：音频内容、其它目录、任何账号信息
- 设置里一键导出诊断包（zip 内只有日志、系统信息、设置、崩溃记录）

## 三、明确移除的功能

| 功能 | 为什么移除 |
|---|---|
| **「已用」角标** | 判定依赖播放记录，删库/重导入后会残留；逻辑本身不可靠，直接去掉 |
| **省电模式** | 限制 60 fps 治不了根，掉帧的真正原因是卡片实例化成本，改为优化源头 |
| **AI 自动打标签** | 本地 YAMNet 对真实录音（雨声、鸟叫）可识别，但对拟音/合成音效准确率不足——"拔刀"被识别成"玻璃破碎"。错标签比没标签更麻烦，连 15 MB 模型一起删除，exe 从 93.2 MB 回到 73.4 MB |

## 五、兼容与升级

- **覆盖安装**：安装包会自动关掉正在运行的音匣，数据（`store.json` / `index.db`）保留
- **老库不用重新导入**：之前存过的波形不会重算
- **便携模式**：exe 旁边有 `data\` 就用它
- **配置项新增**：`ScrollAnim`、`ScrollAnimMs`（旧配置读进来会自动补默认值）
