# 音匣 SoundVault v1.0.3

> 本地音效库管理器。Windows 10 / 11 · WPF (.NET 10) · 单文件 exe · 不联网、不移动、不复制、不改你的文件。

对外版本号：**1.0.3**。这个目录里是 1.0.3 的最终源码。

## 这一版有什么不同

| | |
|---|---|
| 右侧详情栏 | 规格、评分、收藏、标签；只选中一条时展开，`Esc` 收起 |
| 波形选区 | 拖动划段、`I`/`O` 标入点出点、`X` 清空、`←`/`→` 跳步，有选区时只循环这一段 |
| 播放头高亮 | 听到哪、波形亮到哪（卡片与详情栏都生效） |
| 列表视图 | 网格/列表切换；名称列双竖线手柄可拖宽、双击复位、宽度记忆 |
| 全局快捷浮窗 | `Ctrl+Alt+S` 呼出、搜全库、**直接把音效拖进 DAW**；可拖动、置顶、热键开/关、可自定义 |
| 托盘 / 开机自启 | 关窗驻留；`--hidden` 静默进托盘 |
| 四语言 | 跟随系统 / 简 / 繁 / English，切换即时生效 |
| 支持作者 | 独立赞赏页，完全自愿，不影响功能 |
| 日志 | 概括 + 错误 + 慢操作常驻，逐文件细节进内存黑匣子；按时间窗导出，附 `failures.csv` |

修掉的问题（96k WAV 无声、mp3 波形死循环、波形尾巴被吃掉、`10_` 排到 `1_` 前、语言切换无效等）逐条写在 [`修改意见.md`](修改意见.md)，
用户手册见 [`使用说明书.md`](使用说明书.md)。

## 构建

需要 .NET 10 SDK。

```powershell
cd v1.0.3        # 就是本目录
.\build.ps1 -Version 1.0.3                 # 应用 + 安装包
.\build.ps1 -Version 1.0.3 -SkipInstaller # 只出应用
.\tools\verify-all.ps1                    # 全量验收（31 项）
```

产物在 `_local\dist\`：`音匣.exe`（约 73 MB）+ `SoundVault-1.0.3-Setup.exe`。
