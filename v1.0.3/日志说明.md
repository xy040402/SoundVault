# 音匣 1.0.3 · 日志说明

> 目标：出了问题能定位到「哪个文件、哪个环节、为什么」，同时不让日志把磁盘撑爆。

---

## 一、分层

| 类型 | 写不写盘 | 内容 |
|---|---|---|
| 概括 | 立刻写 | 每次操作的开始 / 完成 / 统计 |
| 失败 | 立刻写 | `fail file="…" stage=peaks ms=8 why="…"` |
| 慢 | 立刻写 | 单文件超过 300 ms |
| 用户动作 | 立刻写 | 入点/出点/清空、标签、评分、收藏、重命名、拖到 DAW、浮窗、导出 |
| 详细 | 只进内存 | 每个文件每个阶段一行，最多 500 行的环形缓冲 |
| 黑匣子 | 触发时 | 出错、卡住、用户导出时把缓冲整段倒进日志 |

## 二、黑匣子与看门狗

- `Log.Trace(...)` 只写内存，正常情况不产生任何磁盘开销
- `Log.DumpBlackBox(原因)` 把缓冲倒进正式日志并清空
- 每处理完一个文件调一次 `Log.Beat(...)`；**15 秒**没有新心跳就判定卡住，自动倒出黑匣子，并写明最后处理的是哪个文件

这条是专门治「卡住但不报错」的：以前那种进度条不动、日志里什么都没有的情况，现在会把现场交出来。

## 三、体积

| 场景 | 磁盘 |
|---|---|
| 4 个文件导入 + 补波形 | 约 4 KB |
| 4213 个文件全库扫描 | 约 40 KB |
| 10 万文件 | 约 0.5–1 MB |
| 滚动 | 单文件 5 MB，保留 5 个 |

## 四、按时间窗导出

- 界面：设置 → 数据与日志 → 导出诊断包，可选最近 10 / 20 / 30 分钟、1 / 2 小时、1 天、全部，可勾「只导出警告和错误」，并实时显示预估行数与体积
- 命令行：`音匣.exe --exportlog <zip> [分钟|all] [warn]`
- 包内容：

| 文件 | 内容 |
|---|---|
| `log.txt` | 按时间窗裁剪后的日志 |
| `failures.csv` | 所有失败行拆成 7 列（time / level / area / file / stage / ms / why） |
| `system.txt` | 版本、系统、屏幕、数据目录 |
| `readme.txt` | 导出时间、时间窗、行数、失败行数 |

## 五、动作埋点覆盖

| 区域 | 记录 |
|---|---|
| scan / wave | 开始、进度、完成、失败、慢操作 |
| clip | 入点、出点、清空 |
| tag / rate / fav | 加标签、改星级、切收藏 |
| rename / drag | 批量重命名、拖到 DAW |
| shell / hotkey | 浮窗开关、热键注册结果 |
| export / support | 导出日志、打开赞赏页 |
