# 音匣 1.0.3 · 支持作者（赞赏）

> 入口：设置 → **支持作者**（与常规/外观同级的一级页）
> 原则：完全自愿、不影响任何功能、没有付费版、启动不弹窗。

## 界面

| 元素 | 内容 |
|---|---|
| 说明 | “音匣免费、开源、无广告，也没有付费版。如果它帮到了你，可以请作者喝杯咖啡——完全自愿。” |
| 按钮 | `微信赞赏` `支付宝`（`爱发电` 预留，未配置链接所以隐藏） |
| 弹窗 | 420×470，白底二维码区 250×250，底部「保存图片 / 关闭」 |

## 图片（已接入）

放的位置：`src/SoundVault.App/Assets/`，工程里按存在与否条件打包：

```
Assets/support-wechat.png   900×900  微信赞赏码（已裁成正方形白底）
Assets/support-alipay.png    900×900  支付宝收钱码（已裁成正方形白底）
```

裁剪只保留二维码本身，原图里的昵称/姓名没有进仓库。

## 埋点

```
[support] open kind=wechat loaded=True
[support] open kind=alipay loaded=True
[support] save <路径> kind=wechat
```

`loaded=True` 表示二维码图片已从程序资源里正常加载。

## 验证

用离屏探针确认过两个码都能加载：

```
[support] probe root=Border w=404 h=431 bg=#FF16181D title="微信赞赏码"
[support] probe root=Border w=404 h=431 bg=#FF16181D title="支付宝赞赏码"
```
