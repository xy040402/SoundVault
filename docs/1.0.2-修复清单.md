# 音匣 1.0.2 修复清单

> 这一版修了什么。每条都是"以前怎样 → 现在怎样"，括号里是实测数字。

## 导入

- **大库导入要等很久**：扫描不再把每个文件读完，只读文件头，波形交给后台补。（1.48 GB / 60 文件 1709 ms → 20 ms；10 万文件 10.1 秒）
- **补波形结束时卡 1–2 秒**：不再重建整库卡片，只把新峰值贴回可见卡片。（5 千库 28 ms）
- **导入进度条看着不动**：填充元素宽度为 0，缩放乘在 0 上，已修好。
- **导入时先显示空视图再刷**：改成扫描完成后库才出现。
- **补波形被中断就白算**：改成下次启动接着补。（实测中断后剩余 26,000 个自动续上）

## 搜索

- **打字一顿一顿**：整库卡片只造一次 + 拼音预热 + 逐字增量过滤 + 110 ms 防抖。（拼音首查 49 ms → 1 ms）
- **搜索只搜当前库**：改成跨库搜索。
- **第一次进搜索要等**：启动后台预热，用户点搜索时缓存已就绪。（10 万条约 1 秒，用户不等）

## 快捷入口

- **「全部音效」只显示当前库**：全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 改成全部库范围。
- **面包屑带着库名**：跨库视图的路径里不再出现某一个库的名字。
- **没有库时点快捷入口报错**：改成显示空状态。

## 视图与滚动

- **文件夹和音效不能同时显示**：库根现在上面一排文件夹卡片、下面根目录音频。
- **换视图后底部一大片空白**：不再沿用上一个视图的滚动位置，换内容时归零。
- **某些页面滚轮几乎滚不动**：面板可滚动高度算成 0（只 Arrange 没 Measure），已修。
- **滚轮是"闪现"**：左右两栏改成逐帧缓动，可关闭，速度三档（100 / 140 / 220 ms），跟随系统动画设置。
- **10 万条滚动掉帧**：卡片加位图缓存 + 波形柱数减半。（31–49 fps → 52–97 fps）
- **进度条一行字挤在一起**：改成两行，第一行说明，第二行数字/百分比/剩余/文件名 + 取消，整体居中。

## 安装与卸载

- **安装失败说不清原因**：失败页给中文原因 + 错误码 + 磁盘可用空间，可「复制诊断信息」「打开日志目录」。
- **勾了开始菜单快捷方式却没出现**：直接建在 `Programs\` 根，装完当场校验，失败退回 WScript 再建。
- **弹出 Windows 原生对话框**：关旧版本、卸旧版本、删数据确认全部改成向导内页面。
- **卸载残留、双击卸载文件打开错界面**：进程状态重置 + 入口判断修正。

## 设置面板

- **设置面板结构混乱**：改成左导航 + 五页（常规 / 外观 / 导出与命名 / 数据与日志 / 关于）。
- **改外观要另开窗口**：外观内嵌进设置页，改完即时预览，点取消还原。
- **主色只能现调现丢**：加了「最近使用」（8 个）和「收藏」（10 个）。
- **置顶时亮错图标**：按钮状态读错变量，已修。
- **浅色主题下悬停色看不见**：颜色写死成 `#10FFFFFF`，改成主题资源。
- **设置导航点了不切换**：改掉自定义容器不触发 `SelectionChanged` 的问题。

## 库管理

- **删库后重新导入还显示旧状态**：删库时一并清掉评分、收藏、播放记录、集合引用、标签关联。
- **智能文件夹右键删不掉**：右键事件被列表控件吃掉，改用 Preview 事件 + 命中行选中。
- **库根直接放音频时视图空白**：有子文件夹就只走文件夹分支，已修。
- **「已用」判定不可靠**：删库/重导入后会残留，直接移除这个功能。

## 播放

- **96k 音频放不出来**：容器嗅探与解码两处补齐。

## 移除的功能

- 「已用」角标 —— 判定依赖播放记录，不可靠。
- 省电模式 —— 限制 60 fps 治不了根，掉帧的真正原因是卡片实例化成本。
- AI 自动打标签 —— 对拟音/合成音效准确率不足（拔刀被认成玻璃破碎），连 15 MB 模型一起删，exe 从 93.2 MB 回到 73.4 MB。
