## 音匣 SoundVault 1.0.2

以性能为主的更新：大库导入不再等，搜索和滚动不再卡。

### 亮点

- **两阶段索引**：扫描只读文件头，波形后台补。1.48 GB / 60 文件实测 **1709 ms → 20 ms**；10 万文件扫描 10.1 秒
- **秒搜**：整库缓存 + 拼音预热 + 增量过滤 + 防抖，拼音首查 **49 ms → 1 ms**
- **文件夹与音效同屏**：库根同时显示子文件夹和根目录音频
- **快捷入口跨库**：全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 全部跨库；库与文件夹仍只看本库
- **滚轮平滑滚动**：左右两栏逐帧缓动，设置里可关、三档速度，跟随系统动画设置
- **进度条两行**：说明 + 数字/百分比/剩余/文件名 + 取消

### 修复

- 补波形结束时整库重建造成的 1–2 秒卡顿（改为只刷新可见卡片，5 千库 28 ms）
- 换视图后沿用旧滚动位置，导致底部大片空白
- 部分页面 `extent` 为 0 导致滚轮几乎滚不动
- 10 万条滚动帧率 31–49 → 52–97 fps

### 移除

- AI 自动打标签（YAMNet）：对拟音 / 合成音效准确率不足（拔刀被认成玻璃破碎），连模型一起删除，exe 回到 73.4 MB

### 安装

下载 `SoundVault-1.0.2-Setup.exe`，覆盖安装即可，数据保留；老库不需要重新导入。
