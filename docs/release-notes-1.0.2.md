## 音匣 SoundVault 1.0.2

以性能为主的更新：大库导入不再等，搜索和滚动不再卡。

### Q & A

以下内容均来自b站评论区的问题。感谢以下b站用户的反馈！！！

1. **Q（from 皮皮喵猫喵）：**显示导入进度，不然就卡死在这里了。以及用everthing的方式找，不然文件太多死翘翘。
   **A：**显示导入进度条的问题已经完成。everything这一点，先说明一下，everything是不读文件的，只读索引，所以everything查找非常快。已优化这一功能。
2. **Q（from xiluo520）：**有办法分析音频后给出标签吗？
   **A**目前暂时无法做到。我自己有尝试这个功能，这个功能是能做的，但是难就难在ai打标签这一块，非常的诡异。我拿了一个古风剧里会用到的“拔刀”的音效，ai打的tag是玻璃破碎。这种效果肯定是不能拿上台面的，所以暂时取消这个功能。
3. **Q（from 千空i）：**这个添加进这个音效软件里的文件是以索引的方式还是又复制了一份在这个音效软件的专属文件夹中
   **A：**是索引，所以音效源文件记得保留不要删~
4. **Q（from 今晚谁做饭）：**有没有mac端呀
   **A：**该项目为WPF项目，只能在Windows端运行。第一，如果需要做mac端需要几乎重写整个项目，比较麻烦。第二，本人没有mac设备，所以即使写了一个mac版本，也没有办法给各位进行测试和改错。所以暂不制作mac版本。
5. **Q（from 风_你好）：**目前的情况是导入音频文件过于缓慢，几千个音频文件需要十分钟左右，百万级别的话 就太耽误时间了。**A：**v1.0.0版本的时候，每个音频的音波显示，是在导入的同时运行的，而算音波是需要读文件的。所以基本上大多数的导入时间都在这里耽误了。目前我还没有能找到能对标eagle那种速度的方式。但我已经做了优化，将导入和算音波分开来进行。在导入之后即可看到导入完成，并可以进行部分操作，但仍然强烈建议等音波全部算完之后，再进行其他操作。
6. **Q（from 迅捷数码达人）：**音频采样率96的无法播放吗？
   **A：**已确认为bug，导致aiff或者aif的音频无法播放。目前已修复。
7. **Q（from liyesok）：**我安装时提示这个怎么办（无法安装）：Unknown Hard Error
   **A：**已加入“日志”功能，如果有问题，请把日志文件和遇到的问题详细说明之后打包发一个邮件到2284673040@qq.com

### 亮点

- **两阶段索引**：扫描只读文件头，波形后台补。1.48 GB / 60 文件实测 **1709 ms → 20 ms**；10 万文件扫描 10.1 秒
- **秒搜**：整库缓存 + 拼音预热 + 增量过滤 + 防抖，拼音首查 **49 ms → 1 ms**
- **文件夹与音效同屏**：库根同时显示子文件夹和根目录音频
- **快捷入口跨库**：全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 全部跨库；库与文件夹仍只看本库
- **滚轮平滑滚动**：左右两栏逐帧缓动，设置里可关、三档速度，跟随系统动画设置
- **进度条两行**：说明 + 数字/百分比/剩余/文件名 + 取消

### 修复

- 补波形结束时整库重建造成的 1–2 秒卡顿（改为只刷新可见卡片，5 千库 28 ms）
- 换视图后沿用旧滚动位置，导致底部大片空白
- 部分页面 `extent` 为 0 导致滚轮几乎滚不动
- 10 万条滚动帧率 31–49 → 52–97 fps

### 移除

- AI 自动打标签（YAMNet）：对拟音 / 合成音效准确率不足（拔刀被认成玻璃破碎），连模型一起删除，exe 回到 73.4 MB

### 安装

下载 `SoundVault-1.0.2-Setup.exe`，覆盖安装即可，数据保留；老库不需要重新导入。
