## 8. 明确不做（避免反复讨论）

| 不做 | 原因 |
|---|---|
| 云端素材库 / 在线商店 / 账号 | 本地优先是产品定位 |
| AI 语音生成 / 声音克隆 / 音效合成 | 不做内容生产 |
| 多轨音频编辑 / 降噪 / 混响 | 精修交给 RX / DAW |
