# 音匣 SoundVault 1.0.0

第一个正式版。

### 下载

**只提供一个文件：`音匣安装包.exe`** —— 双击安装，装完即可用。

- 无需预装 .NET（单文件自包含）
- 装到 `C:\Program Files` 会弹一次 UAC；装到用户目录不需要
- 安装位置会自动补 `SoundVault` 子目录（选 `D:\Apps` 就是 `D:\Apps\SoundVault`）
- 不提供单独的绿色版 `音匣.exe`：装完从安装目录拷出来即可，或自己 `.\build.ps1` 构建

### 亮点

- **搜得快**：拼音首字母（`bdx` → 拔刀相向）+ 过滤语法（`#标签` `star:>=4` `dur:<2s` `sr:>48k` `ch:2` `type:wav`）
- **听得顺**：鼠标悬停即循环试听；波形上按住拖播放头；LUFS 归一化试听
- **整理得动**：五星评分、收藏、标签、集合（可重命名/删除/踢出音效）、重复检查、批量重命名（带预览）
- **交付得出去**：拖进 DAW、`Ctrl+C` 复制文件、批量导出（命名模板 + 保留目录结构 + CSV 清单）
- **装得干净**：安装器会检测"正在运行"和"旧版本装在别处"；卸载有向导，可选是否连数据一起删（默认保留）
- **看得舒服**：深浅色、自定义主色、面板透明度、圆角、Win11 云母；首次启动 6 步新手引导

### 说明

- 仅 **Windows 10 / 11 x64**
- 单文件**未做代码签名**，SmartScreen 可能提示"未知发布者"
- 不联网、不收集任何数据；不改变你的音频文件
- 详细用法：[使用说明书](docs/使用说明书.md)（19 章，含常见问题）
- 数据位置：`%LocalAppData%\SoundVault\`（`store.json` + `index.db`），卸载默认保留

### 已知限制

- 网络盘 / 移动硬盘扫描会慢一些
- 拖拽到某些宿主不生效时，用 `Ctrl+C` 复制文件再粘贴
