01 材质分层 —— 玻璃只做容器，内容永远是主角

三层材质各司其职。L0 是系统级 Mica（透出桌面），几乎零成本；L1 是自绘霜面，只用在左栏 / 顶栏 / 试听条这类"容器"上；L2 是卡片与按钮的液态感，靠边光和高光而非模糊。

L0 · 底板 Mica窗口整体 · 系统级 · 0.2ms
L1 · 霜面 Frost左栏 / 顶栏 / 试听条 · 模糊 18px
L2 · 液态 Liquid卡片 / 按钮 · 高光 0–18% · 不模糊

判据：如果一层玻璃背后没有"值得被模糊的内容"，就不要给它加模糊 —— 那是纯损耗。

03 主界面 · 浅色

浅色不是深色的反相：面板白度提高到 60–78%，边光改为亮白描边，阴影更柔更浅；波形改中性灰蓝，避免在浅底上"发飘"。

浅色主题下的关键约束：卡片不透明度不低于 62%，否则波形与文字会与背景糊在一起。

05 关键状态

搜索态与空态是产品"第一次见面"和"每天都在用"的两个极端，必须单独设计；拖拽幽灵是唯一会离开窗口的界面元素。

搜索态：搜索框进入聚焦态（主色描边 + 外发光），面包屑切换为"搜索结果"，命中文件夹以胶囊呈现，结果按相关度排序。

空态：不讲功能，只讲一句动作指令 + 两个出口；底部明确"不会移动、不会修改你的文件"，降低首次导入的心理成本。
