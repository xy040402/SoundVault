### Bug #1 详情：安装包不能装到受保护目录

- **原因**：安装包清单是 `requestedExecutionLevel level="asInvoker"`，以普通用户身份写 `C:\Program Files` 必然被拒。
- **修复**：安装前用 `Installer.CanWriteTo(dir)` 探测目标目录（不存在则看最近存在的父目录）；
  不可写就 `Process.Start(self, "--silent \"<dir>\"")` + `Verb = "runas"` 提权重启自己，静默装完。
  默认的 `%LocalAppData%` 路径仍然不需要 UAC。
- **验证**：修复后装到 `C:\Program Files\SoundVault` 成功。

### Bug #3 详情：评分 / 标签 / 加入到集合 三个子菜单全都不弹

- **原因**：`MenuItem` 的 `ControlTemplate` 里只有「背景 + 勾 + 标题」，**没有 `PART_Popup`**。
  WPF 的 `MenuItem` 靠模板里的 `PART_Popup` 打开子菜单，缺了它 → 带子项的菜单点击/悬停都毫无反应。
- **修复**：模板改成 `Grid{ Border + arrow + Popup(PART_Popup, IsOpen=IsSubmenuOpen, ItemsPresenter) }`，
  并补 `HasItems` 时显示 `›` 箭头、`IsEnabled=False` 时灰显。
- **验证**：开发版与**安装版**都实测悬停出子菜单，评分落库生效。
