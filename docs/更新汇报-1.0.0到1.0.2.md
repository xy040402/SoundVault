# 音匣 SoundVault 1.0.0 → 1.0.2 更新汇报

> 用途：视频汇报脚本 + 素材清单。带 ⏱ 的是可以现场演示的点，带 📊 的是可以直接念的数字。
> 版本节奏：1.0.0 发布（11-01）→ 1.0.1 内部版（11-19 冻结，未发布）→ 1.0.2 发布（11-20）。

---

## 一句话

**1.0.0 是"能用"，1.0.2 是"好用"**：大库导入从"等十分钟"变成"两秒可用"，搜索和滚动不再卡，安装和设置也重做了一遍。

---

## 二、两个版本各自干了什么

| 版本 | 主题 | 主要产出 |
|---|---|---|
| **1.0.1**（内部） | 装得像样、设得明白 | 安装/卸载向导重做、设置面板重做成五页、外观内嵌 + 主色历史与收藏、日志系统与诊断包、导入进度条、开始菜单快捷方式、删库清理 |
| **1.0.2**（发布） | 快 | 两阶段索引（扫描 1709 ms → 20 ms）、秒搜（拼音 49 ms → 1 ms）、文件夹与音效同屏、快捷入口跨库、滚轮平滑滚动、10 万级压测与滚动优化 |

## 三、十个能直接演示的变化

### 1. ⏱ 大库导入：从"等"到"秒开"
- **以前**：为了画波形，扫描时把每个文件从头读到尾，耗时和库的总字节数成正比
- **现在**：扫描只读文件头，波形交给后台补，卡片先出来
- 📊 1.48 GB / 60 个文件：**1709 ms → 20 ms**（快 85 倍）；补波形 2512 ms 在后台跑
- 📊 10 万文件：扫描 **10.1 秒**（约 0.1 ms/文件），补波形 18.1 秒（5,500 个/秒）
- 演示：拖一个几百 MB 的包进去，进度条一闪，卡片就出来了

### 2. ⏱ 进度条重做：两行 + 能取消
- 第一行：`正在补齐波形图，您可以继续操作`
- 第二行：`22 / 40　56%　·　剩余 2 秒　·　AK47_BURST_20.wav` + 进度条 + 取消
- 以前是半透明一条，没颜色变化，看着像"不动"
- 演示：慢速导入时（可用 `SV_SLOW_SCAN`）看它一格一格走

### 3. ⏱ 秒搜
- **以前**：每敲一个字都把全库重读一遍 + 全量过滤排序
- **现在**：整库卡片缓存一次（启动后台预热）、拼音预热、逐字增量过滤、110 ms 防抖
- 📊 拼音首查 **49 ms → 1 ms**；10 万条首次进搜索 53 ms，逐字 2 ms
- 演示：连打 `bd`（拔刀）看结果秒出

### 4. ⏱ 文件夹和音效同屏
- **以前**：有子文件夹时，根目录直接放的音频**看不见**，只能去"全部音效"找
- **现在**：上面一排文件夹卡片，下面就是根目录音频，统计写「3 个文件夹 · 5 个音效（根目录）」
- 演示：建个"3 个子文件夹 + 5 个 wav"的目录拖进去

### 5. ⏱ 快捷入口跨库
- **以前**："全部音效"只显示**当前选中的那个库**
- **现在**：全部音效 / 收藏 / 最近导入 / 最近播放 / 标签 / 重复检查 / 搜索 全是**全库范围**
- 侧栏点某个库或文件夹 → 仍然只看这个库（作用域在面包屑上看得出）
- 演示：两个库，点"全部音效"，统计显示「N 个音效 · 2 个库」

### 6. ⏱ 滚轮平滑滚动
- 以前滚一下直接跳一屏（闪现），现在逐帧缓动
- 设置 → 常规 → 滚动：可关、三档速度（100 / 140 / 220 ms），跟随系统"显示动画"设置
- 📊 10 万条滚动帧率 **31–49 fps → 52–97 fps**

### 7. 安装 / 卸载向导
- 全程向导页，不再弹 Windows 原生对话框
- 保留数据卸载 / 彻底卸载可选；失败给原因 + 一键复制诊断信息
- 开始菜单快捷方式勾了就一定出现（装完当场校验）

### 8. 设置面板重做
- 左导航五页：常规 / 外观 / 导出与命名 / 数据与日志 / 关于
- 外观内嵌：主色（预设 + HEX + 最近使用 8 个 + 收藏 10 个）、面板强度、圆角、云母；即时预览，点取消全部还原

### 9. 日志与诊断包
- `app-*.log` / `setup-*.log`，单文件 5 MB × 5 个
- 设置里一键导出诊断包（只有日志、系统信息、设置、崩溃记录）
- 这次更新的所有性能数字，都是靠这套日志量出来的

### 10. 库管理修正
- 删库时一并清理评分、收藏、播放记录、集合引用、标签关联（以前会留垃圾，重新导入同一个库还显示旧状态）
- 智能文件夹可以右键删除了

## 四、修掉的 bug（按影响排）

| # | 问题 | 根因一句话 |
|---|---|---|
| 1 | 大库导入十分钟 | 扫描阶段为了画波形读了整个文件 |
| 2 | 导入时进度条"看着不动" | 进度条填充元素没写宽度，`ScaleX` 放大还是 0 |
| 3 | 补波形结束卡 1–2 秒 | 补完把整库卡片重建 → 改成只贴可见卡片的峰值（28 ms） |
| 4 | 换视图后底部大片空白 | 沿用了上一个视图的滚动位置 → 换内容时归零 |
| 5 | 某些页面滚轮几乎滚不动 | 面板 `extent` 为 0（只 Arrange 没 Measure） |
| 6 | 删除库再导入仍显示"已用" | 删库没清 `Assets` / 播放记录 → 连带把"已用"整个移除 |
| 7 | 智能文件夹右键删不掉 | 右键事件被 ListBox 吃掉 |
| 8 | 库根放音频时视图空白 | 有子文件夹就只画文件夹 |
| 9 | 96k 音频放不出来 | 两处：容器嗅探 + 解码 |
| 10 | 安装报 `unknown hard error` | 失败原因不可见 → 失败页给原因 + 诊断包 |
| 11 | 置顶时亮错图标（齿轮亮） | 按钮状态读的是 `Topmost` 而不是实际状态 |
| 12 | 浅色主题下按钮悬停色隐形 | 颜色写死成 `#10FFFFFF` |
| 13 | 设置导航点了不切换 | `ListBox` 自定义容器不触发 `SelectionChanged` |
| 14 | 卸载残留、双击卸载文件开错界面 | 进程状态没重置 + 入口判断错 |

## 五、拿掉的三个功能（视频里建议讲，态度比功能重要）

| 功能 | 为什么拿掉 |
|---|---|
| **「已用」角标** | 判定依赖播放记录，删库/重导入后残留，逻辑本身不可靠 |
| **省电模式** | 限制 60 fps 解决不了真正的问题；后来发现掉帧的根因是卡片实例化，于是直接优化源头 |
| **AI 自动打标签** | 本地 YAMNet 对**真实录音**（雨声、鸟叫）能认，但对**拟音/合成音效**准确率不够——最典型一次是"拔刀"被识别成"玻璃破碎"。给一堆错标签比没有标签更糟，连 15 MB 模型一起删了，exe 从 93.2 MB 回到 73.4 MB |

> 口播建议：**"能识别"和"识别得准"是两件事。我宁可删掉这个功能，也不想让你挨个删错标签。"**

## 七、兼容与升级

- **直接覆盖安装**：安装包会自动关掉正在运行的音匣，数据（`store.json` / `index.db`）保留
- **老库不用重新导入**：1.0.1 及以前存过的波形不会重算
- **补波形可中断**：中途退出或取消，下次启动接着补（实测中断后剩余 26,000 个自动续上）
- **便携模式不变**：exe 旁边有 `data\` 就用它

## 九、口播稿（约 4 分钟，可直接念）

**[开场 15 秒]**
> 这次从 1.0.0 到 1.0.2，没有加花哨功能。做的事只有两件：把该快的弄快，把该说清楚的弄清楚。

**[大库导入 40 秒]**
> 先说最疼的：以前导入一个大音效库，它要为了画波形，把每个文件从头读到尾。文件越多、越大，你就等得越久。
> 现在扫描只读文件头，波形丢到后台慢慢补。1.48 GB 的库，从 1.7 秒变成 20 毫秒——库立刻能用，波形在后面自己长出来。
> 十万个文件实测，十秒扫描完，十八秒补完波形，这十八秒里你能正常听、正常搜。

**[搜索 30 秒]**
> 搜索以前每敲一个字都把全库重读一遍。现在整库只读一次，还在启动时就偷偷准备好了；拼音首查从 49 毫秒到 1 毫秒，敲一个字结果就出来。

**[界面 40 秒]**
> 界面上修了几个"看着难受"的地方：进度条改成两行，第一行告诉你还能继续操作，第二行是具体数字；文件夹和音效现在能同时显示，不用再切"全部音效"去找；快捷入口以前只看当前库，现在跨库，但你点某个库还是只看那个库。滚轮也从"闪现"改成了滑动，速度可调。

**[删功能 40 秒]**
> 这次还删了三个功能。AI 自动打标签，模型是真的能认雨声鸟叫，但音效库里大量是拟音和合成音，它把"拔刀"认成了"玻璃破碎"。给一堆错标签，比没有标签更糟——所以我连 15 MB 的模型一起删了。
> 还有"已用"角标和省电模式，前者的判定本身不可靠，后者解决不了掉帧的根本问题。

**[收尾 20 秒]**
> 1.0.2 已经发布，安装包在 Release 里。老库不用重新导入，数据都在。下一步想做的事写在仓库的待办里，欢迎提意见。
