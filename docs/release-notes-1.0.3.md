# 音匣 SoundVault v1.0.3

本地音效库管理器 · Windows 10/11 · 不联网、不移动、不复制、不改你的文件

这一版主要做两件事：**把「找到之后怎么交出去」打通**（右侧详情栏、波形选区、列表视图、全局浮窗直接拖进 DAW），以及**修掉几个会让界面看起来"坏掉"的问题**（mp3 波形永远补不完、波形尾巴缺失、`10_` 排到 `1_` 前面）。

---

## 新增

- 右侧详情栏：选中一条后显示格式 / 时长 / 采样率 / 位深 / 声道 / 大小，评分、收藏、标签都在这里改
- 波形选区：在波形上拖动划段，`I` 标入点、`O` 标出点、`X` 清空，试听只循环这一段
- 条目内跳步：`←` `→` 长于 50 秒每次跳 5 秒，短的每次跳 1/10 时长
- 播放头高亮：听到哪、波形亮到哪，卡片和详情栏都生效
- 列表视图：网格 / 列表一键切换，每行显示名称、规格、波形、时长、格式、评分、收藏
- 名称列可拖宽：拖动名称右侧的双竖线手柄，双击复位，宽度会记住
- 全局快捷浮窗：`Ctrl+Alt+S` 呼出，搜索**所有库**，不限于当前文件夹
- 浮窗直接拖进 DAW：拖动时浮窗半透明并让开鼠标，宿主能正常接住
- 浮窗可拖动、可置顶、点别处不消失，热键再按一次关闭，右上角也有 `×`
- 自定义快捷键：设置里「录制」按下组合即可，默认组合被占用会自动降级
- 托盘常驻：关窗只隐藏，左键打开、右键「打开音匣 / 快捷搜索 / 退出」
- 开机自启：勾选后启动直接进托盘，不闪窗口
- 界面语言：跟随系统 / 简体中文 / 繁體中文 / English，切换即时生效
- 搜索增强：同义词（转场↔transition/whoosh 等约 75 组）、繁简通、驼峰与分隔符自动归一
- 常用搜索词：搜索框下方胶囊，左键搜、右键删、`＋` 添加
- 排序方向记忆：名称 / 时长 / 评分 / 导入顺序各自记住升降序
- 「可能相关」补位：字面结果很少时按相似度补一截，状态栏会注明其中几条是猜的
- 支持作者页：微信赞赏 / 支付宝，完全自愿，不影响任何功能也没有付费版
- 日志体系：平时记概括、错误、慢操作和你的操作；逐文件细节放在内存里，出错或卡住才落盘
- 按时间窗导出日志：最近 10/20/30 分钟、1/2 小时、1 天、全部，可只导警告错误
- 导出包附 `failures.csv`：把失败行拆成表格，直接能看出哪个文件、哪个环节、什么原因

## 改进

- 长音频（>60 秒）的波形改为概略采样，几秒出结果，不再逐个全解码
- 波形补算改成每 200 个一批，边补边显示，不用等整库完成
- 卡片去掉整卡缓存，播放头扫过时不再整张重新渲染（CPU 1.9% → 0.6%）
- 详情栏波形改为几何缓存，每帧只画两次，不再逐根画柱子
- 多声道降混改为按通道掩码加权：中置、环绕、LFE 都混进来，叠加超过 0 dBFS 自动限幅
- 名称排序改为自然序，`1_` `2_` `9_` `10_` `11_` 按人类顺序排
- 96 kHz / 24bit / 多声道 WAV 统一走规范 PCM 流，播放更稳

## 修复

- 修复 mp3 的波形永远补不完（进度一直停在「正在补齐波形」，重开继续补）
- 修复波形最右边一段画不出来（窗口越宽丢得越多，最多丢掉 25% 的内容）
- 修复 4 个「MP3 改名成 .wav」的文件让波形进度分子涨到几十万、界面卡死
- 修复 96 kHz / Extensible 格式的 WAV 点了没声音，提示 `Unsupported source encoding`
- 修复 6 声道文件读取时报 `Must read complete blocks` 而无法播放
- 修复部分多声道 WAV 读不到通道布局，降混时丢掉中置和环绕
- 修复文件夹按名称排序时 `10_` 排在 `1_` 前面
- 修复切换界面语言后页面没有任何变化
- 修复导出日志对话框的勾选框文字看不见
- 修复导出日志里「最近 1 小时 / 1 天」实际按 1 分钟和 30 分钟计算
- 修复点一下波形就丢掉已设好的入点出点
- 修复 `I` / `O` 标记的位置和播放头对不上
- 修复收起右侧详情栏后列表右边留白
- 修复托盘图标不显示（单文件程序里取不到资源图标）

## 安装

1. 下载 `SoundVault-1.0.3-Setup.exe`，双击安装（默认装在 `%LocalAppData%\Programs\SoundVault`，不需要管理员权限）
2. 覆盖安装会保留库、评分、标签等数据；卸载时可选保留或删除配置
3. 想便携使用：把安装目录里的 `音匣.exe` 复制到任意文件夹，同级新建 `data\` 空目录即可

## 已知限制

- 仅支持 Windows 10/11（WPF），没有跨平台计划
- 网络盘 / 移动硬盘首次扫描会慢一些
- 拖到个别宿主不生效时，用 `Ctrl+C` 复制文件再粘贴，或从浮窗再拖一次
- 单文件未签名，SmartScreen 可能提示"未知发布者"
- 英文界面覆盖主界面与设置，右键菜单等少部分文案仍是中文

## 反馈

- 使用问题：先看仓库里 `v1.0.3/使用说明书.md` 的「常见问题」
- 提 bug：附上「设置 → 数据与日志 → 导出诊断包」生成的 zip（可选最近 10~30 分钟，里面含日志、系统信息和失败清单）
